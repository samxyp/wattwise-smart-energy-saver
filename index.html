01

One main prepaid / smart meter

Reads the whole home's total kWh. It can show whether total usage is rising, but normally cannot identify how much each individual appliance used.

Whole-home total
02

Smart meter data connection

If the meter supports a documented API, HAN, or another approved data interface, a future backend/gateway could import readings with the owner's permission.

Requires compatible meter + integration
03

Appliance-level monitoring

Use compatible smart plugs for plug-in devices or circuit-level sub-meters installed by a qualified electrician. These provide separate measurements for selected loads.

Separate device / circuit readings
How WattWise would combine the data

The app could compare the main meter's total with the sum of measured sub-meter or smart-plug readings. If only a main-meter reading is available, WattWise should display the whole-home total and keep per-appliance figures clearly labelled as estimates. It must not pretend that one meter has measured each appliance individually.
